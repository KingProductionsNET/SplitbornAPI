API Documentation

Welcome to the official API documentation. This API allows you to manage users and retrieve data easily.

Introduction

This API is built for simplicity and speed. Base URL:

https://api.example.com/v1

Authentication

All requests require an API key:

Authorization: Bearer YOUR_API_KEY

Get User GET

Fetch a user by ID.

GET /users/{id}

Example Response

{
  "id": 1,
  "name": "John Doe",
  "email": "john@example.com"
}

Create User POST

Create a new user.

POST /users
Content-Type: application/json

Request Body

{
  "name": "John Doe",
  "email": "john@example.com"
}

Example Usage

JavaScript fetch example:

fetch("https://api.example.com/v1/users/1", {
  headers: {
    "Authorization": "Bearer YOUR_API_KEY"
  }
})
.then(res => res.json())
.then(data => console.log(data));
