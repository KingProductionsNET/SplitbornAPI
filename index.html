SplitbornAPI - NPC Creation 🧠

How To Create A NPC?

Step 1:

Go into the SplitbornAPI's NPC folder and add the name of your NPC into the NPC_ID enum class. Keep the name in caps so it matches the enum feeling.

Step 2:

Create a new folder in Splitborn's NPC plugin named after your NPC name. After that create your main NPC class in that folder which contains the Spawn Method, Click action + listener.

You can also create more classes:

  • NPC_DATA
  • NPC_DIALOGUES
  • NPC_FUNCTIONS
  • NPC_INVENTORY
  • NPC_NCA

Step 3:


private static final String Skin_Signature = "...";
private static final String Skin_Value = "...";
private static final String NAME = "§lAndrew";

Step 4:


public static void Spawn(){
    SplitbornNPC npc = new SplitbornNPC(NPC_ID.ANDREW);
    npc.setName(NAME);
    npc.setSkin(Skin_Value, Skin_Signature);
    npc.setLookClose(true);
    SplitbornAPI.spawnNPC(npc);
}

Step 5:


private static void clickAction(Player player, Entity entity){
    Profile profile = SplitbornAPI.getProfile(player.getUniqueId());

    boolean MetAlly = profile.getBoolean(DATABANK_PATHS.ALLY_MET_PATH_ + NPC_ID.ANDREW.toString());
    boolean CompletedQuest = profile.getBoolean(DATABANK_PATHS.COMPLETED_QUEST_PATH_ + Quests.DEFEAT_ROTMAW.toString());

    if (MetAlly && !CompletedQuest){
        ANDREW_FUNCTIONS.NEW_HANDLE_WALL_OPEN_ANIMATION(player);
        return;
    }

    if (!MetAlly){
        ANDREW_DIALOGUES.NEW_PART_1(player);
        return;
    }

    ANDREW_INVENTORIES.ShopInventory(player);
}

Step 6:


@EventHandler
public void onClick(NPCInteractEvent event){
    Player player = event.getPlayer();
    if (event.getNPCID().equals(NPC_ID.ANDREW)){
        clickAction(player, event.getBukkitEntity());
    }
}
